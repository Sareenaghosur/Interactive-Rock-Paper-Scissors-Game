## 🎮 About The Project

Welcome to **Interactive Rock Paper Scissors Game!**

This project brings the classic Rock Paper Scissors game to life with an interactive web interface. Challenge the computer, make your choice, and see who wins!

Whether you're looking for a little fun or exploring the fundamentals of web development, this project demonstrates how HTML, CSS, and JavaScript can work together to create an engaging browser experience.

## ✨ Features

- 🎯 **Interactive Gameplay** – Choose Rock, Paper, or Scissors.
- 🤖 **Computer Opponent** – Play against the computer.
- ⚡ **Instant Results** – See the outcome of each round.
- 🎨 **Attractive UI** – Clean and engaging game interface.
- 🌐 **Browser-Based** – No installation required.
- 📱 **Responsive Design** – Enjoy the game across different screen sizes.

## 🚀 Getting Started

Follow these simple steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Sareenaghosur/Interactive-Rock-Paper-Scissors-Game.git
```

### 2. Navigate to the Project Folder

```bash
cd Interactive-Rock-Paper-Scissors-Game
```

### 3. Run the Application

Open `index.html` in your preferred web browser.

That's it! You're ready to play! 🎉


## 🧠 Game Rules

The rules are simple:

| Choice | Beats |
|---|---|
| ✊ Rock | ✌️ Scissors |
| ✋ Paper | ✊ Rock |
| ✌️ Scissors | ✋ Paper |

### 🏆 How to Win

- Rock beats Scissors.
- Paper beats Rock.
- Scissors beats Paper.
- Same choices result in a Draw.
